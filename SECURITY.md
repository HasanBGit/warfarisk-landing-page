# Security

## What this project is

A static website. It has no backend, no accounts, no forms, no analytics and no cookies. The page stores nothing in the browser and sends nothing anywhere. The one outside request is the Inter font from Google Fonts.

## Reporting a problem

Please report a vulnerability privately. On the repository page, open the Security tab and choose "Report a vulnerability". Do not open a public issue for a security problem.

Please include what you found, where, and how to reproduce it.

## Supported versions

Only the latest release is supported.

## Medical safety is separate

The dose and range on this page are outputs of a research prototype and are not for clinical use. If you find a number or a claim that does not match the papers, that is a content error, not a security problem. Please open a "Content correction" issue.
